# EDA авиаперевозок: Анализ удовлетворённости пассажиров авиакомпании ✈️

## 📌 Цель проекта

Выявить ключевые факторы, которые влияют на итоговую удовлетворённость пассажиров авиакомпанией. 
Определить, какие характеристики перелёта (класс обслуживания, задержки, онлайн-сервисы, питание и т.д.) вносят наибольший вклад в оценку "удовлетворён" или "не удовлетворён".

## 📁 Данные

- **Источник:** учебный датасет, НИУ ВШЭ
- **Размер:** 10366 строк, 25 столбцов
- **Основные поля:**  
  - Satisfaction — удовлетворённость авиакомпанией — целевая переменная (satisfaction/neutral/dissatisfaction).
  - Flight distance— расстояние перелёта
  - Departure Delay in Minutes — задержка вылета
  - Arrival Delay in Minutes — задержка прилёта
  - Class — класс обслуживания (Business, Economy, Eco Plus)
  - Gender — пол пассажира (женский, мужской)
  - Customer Type — тип клиента (постоянный/непостоянный клиент);
  - Age — возраст клиента;
  - Type of Travel — цель перелета (личная/деловая поездка);
  - Inflight wifi service — уровень удовлетворённости Wi-Fi (0 — не применимо, 1–5);
  - Departure/Arrival time convenient — уровень удовлетворённости временем отправления и прибытия;
  - Ease of Online booking — уровень удовлетворённости онлайн-бронированием;
  - Gate location — уровень удовлетворённости расположением выхода на посадку;
  - Food and drink — уровень удовлетворённости едой и напитками;
  - Online boarding — уровень удовлетворённости онлайн-регистрацией;
  - Seat comfort — уровень удовлетворённости комфортом сидений;
  - Inflight entertainment — уровень удовлетворённости развлечениями на борту;
  - On-board service — уровень удовлетворённости сервисом на борту;
  - Leg room service — уровень удовлетворённости местом для ног;
  - Baggage handling — уровень удовлетворённости обработкой багажа;
  - Check-in service — уровень удовлетворённости услугами регистрации;
  - Inflight service — уровень удовлетворённости обслуживанием во время полёта;
  - Cleanliness — уровень удовлетворённости чистотой;

## 🎯 Основные выводы (для бизнеса)

1. **Главный портрет довольного пассажира:**  
   Постоянный клиент, летящий в деловую поездку бизнес-классом.

2. **Главный портрет недовольного пассажира:**  
   Клиент, летящий в личных целях эконом-классом.

3. **Топ-5 факторов, сильнее всего влияющих на удовлетворённость:**
   - Онлайн-регистрация (разница оценок между довольными и недовольными: 1.4 балла)
   - Развлечения на борту (1.1)
   - Комфорт сидений (0.9)
   - Сервис на борту (0.8)
   - Чистота / Удобство места для ног (0.8)

4. **Что почти не влияет:**
   - Расположение выхода на посадку (Gate location)
   - Время отправления и прибытия (разница всего 0.2 балла)

5. **Неожиданный инсайт:**  
   У командировочных самая низкая оценка — за *время отправления и прибытия* (вероятно, время для них критично). А у отдыхающих — наоборот, этот параметр в топе.

## 🔧 Инструменты и стек

- **Язык:** Python
- **Анализ данных:** pandas, numpy
- **Визуализация:** pandas
- **Среда:** Jupyter Notebook

## 📊 Что сделано в проекте

1. **Загрузка и первичная очистка данных:** проверка пропусков, типов данных
2. **Исследовательский анализ:**
   - Распределение целевой переменной (удовлетворён / неудовлетворён)
   - Анализ влияния пола, возраста, типа поездки, класса обслуживания
   - Сравнение средних оценок по всем сервисным параметрам (Wi-Fi, еда, чистота и т.д.)
3. **Сегментация клиентов:**
   - Выделены 4 ключевые группы: постоянные/непостоянные, цель поездки, класс
4. **Формулирование рекомендаций** на основе числовых различий в оценках

## 📈 Ключевые цифры из анализа

| Показатель | Довольные | Недовольные |
|------------|-----------|--------------|
| Доля клиентов | 43% | 57% |
| Средний возраст | 41.5 лет | 37.6 лет |
| Средняя дальность полёта | 1537 км | 935 км |
| Оценка онлайн-регистрации (из 5) | 4.01 | 2.66 |
| Оценка комфорта сидений (из 5) | 3.95 | 3.01 |

## 🧠 Гипотезы, проверенные в проекте

- Пол и возраст **не влияют** на удовлетворённость.
- Дальность перелёта **не влияет** (довольные летают даже дальше).
- Пассажиры бизнес-класса **значительно чаще довольны**, чем экономом.
- Люди, летящие за личный счёт, в 3 раза чаще недовольны, чем командировочные.
